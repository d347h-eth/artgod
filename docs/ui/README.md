# UI Documentation

Read the first two documents completely before changing a user-visible surface.

1. [User perspective and language](00-user-perspective-and-language.md) — user
   journey, identity, units, errors, consistency, and rendered-review rules.
2. [Interaction guidelines](01-interaction-guidelines.md) — established layout,
   control, navigation, color, pagination, and media behavior.
3. [Preview modal system](02-preview-modal-system.md) — safe media rendering,
   sizing, keyboard behavior, and embedded-content boundaries.
4. [UI testing](03-testing.md) — unit, deterministic Playwright, attached-runtime,
   and required manual rendered inspection.

Collection-specific UI behavior belongs in its
[extension](../extensions/README.md). Admin supervision belongs in
[Desktop](../desktop/README.md).
